# インフォグラフィック: OpenAIのAGIはいつ頃市場向けに提供されるか

見出し
- 誰が何を言っているか
- モデルの進展と評価
- 市場提供のタイムライン（現実的シナリオ）
- リスクと対応（ガバナンス）

要点（概要）
- サム・アルトマン（OpenAI）は『AGIの構築方法が分かってきた』と公言し、2025年にAIエージェントが職場に参加すると述べた。
- 他の専門家や調査では到来予測は2026〜2045年と幅がある。大手研究者の多くは慎重な見方を続けている。
- 技術は局所的・段階的に発展しており、まずは特定タスクで高性能を出す『エージェント型サービス』の普及→その後、より汎用的な能力統合へと進む可能性が高い。

構成（インフォグラフィック向け）
1) 見出し: "OpenAIのAGIはいつ来る？市場提供の現実的な見通し"
2) タイムライン（左から右）: 2024(o3発表) → 2025(Altman発言: エージェントが職場へ) → 2025–2027(エージェント導入・商用化が進む) → 2028–2035(より汎用的機能の統合) → 2040以降(不確実だが一部専門家はここを予測)
3) 出典バブル: Altmanブログ、Forbes、Time、ARC Prize/François Chollet、80000Hours等
4) 3つのシナリオ: 楽観(2025–2029)、中庸(2030–2039)、悲観/長期(2040+)
5) 主要メッセージ: "市場での部分的導入はすぐ来るが、真のAGIの完全な市場化は不確実"

箇条（アクション）
